# CHAYHANA QR Landing

Mobile-first React + Vite landing page for the CHAYHANA restaurant QR code.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Update links

Edit the `LINKS` array in `src/App.jsx` and replace the placeholder Menu, Instagram, Telegram and Address URLs with the restaurant's real links.
